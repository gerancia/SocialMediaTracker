### Facebook — API bloquée
Facebook a verrouillé son API. Même avec un token valide, l'accès aux données publiques des pages nécessite la permission pages_read_engagement qui requiert une vérification officielle par Meta — processus long de 2 à 4 semaines avec politique de confidentialité et site web obligatoires. Le scraping Python retourne un status 400 immédiatement. donc solution retenue : Content Script

### Instagram — API bloquée
Instagram utilise la même API que Facebook (Meta Graph API) et les mêmes restrictions s'appliquent. L'accès aux données d'une page Instagram nécessite d'abord de trouver l'ID Instagram Business via la page Facebook liée, ce qui nécessite les mêmes permissions bloquées. Solution retenue : Content Script.

### TikTok — Pas d'API publique
TikTok n'a pas d'API publique gratuite pour accéder aux données des profils. La TikTok Research API est réservée aux chercheurs académiques. Le scraping Python retourne un status 200 mais les données du profil sont chargées dynamiquement via JavaScript après le chargement initial de la page — elles ne sont pas présentes dans le HTML brut. Solution retenue : Content Script.

### Twitter/X — API payante
Twitter/X a changé son modèle économique en 2023. L'API gratuite ne permet plus de lire les données des utilisateurs — status 402 CreditsDepleted retourné immédiatement. Le plan Basic coûte 100$/mois. Le scraping retourne un status 200 mais les données sont aussi chargées dynamiquement. Solution retenue : Content Script.

---
***Content Script*** — c'est un script JavaScript que l'extension Chrome injecte automatiquement dans une page web quand tu la visites. Il s'exécute à l'intérieur de la page comme s'il en faisait partie, ce qui lui permet de lire toutes les données visibles à l'écran — comme le nombre d'abonnés — sans passer par une API. C'est la solution utilisée pour Facebook, Instagram, TikTok et Twitter car ces plateformes bloquent ou facturent l'accès à leurs APIs officielles
